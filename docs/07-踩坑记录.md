# 踩坑记录

按"坑 → 现象 → 根因 → 解法"记，方便下次少走弯路。

---

## 1. Chromium 窗口挂进壁纸层（WorkerW）后视口坏掉

**现象**：窗口挂上桌面壁纸层了（图标浮在它上面），但页面只画左上角一小块，其它区域黑色。

**实测**：

| 宿主 | 窗口 Win32 尺寸 | 页面 viewport |
|---|---|---|
| WebView2 | 2560×1600 | 580×127 |
| Edge 窗口 | 2560×1600 | 580×127 |
| Electron | 2560×1600 | ~640×110 |

**试过无效**：PerMonitorV2 DPI 清单、延后创建 WebView2、Win32 强改尺寸、
Electron `setBounds`、关闭硬件加速、`enable-transparent-visuals`。

**根因**：Chromium 对"特殊父窗口"的合成器尺寸同步有硬限制。

**解法**：**放弃 WorkerW**。改用「透明窗口 + 动态点击穿透 + z-order 控制」，
这也是开源桌面宠物（xiaokeai / DesktopGirls）的通行做法。

## 2. Electron 透明窗口整屏变白

**现象**：窗口应该是透明的，结果整块白色盖住桌面。

**根因**：`focusable: false` + `win.showInactive()` 的组合。

**解法**：改 `focusable: true` + `win.show()`，并去掉 `setBackgroundColor('#00000000')`。

---

## 3. 透明窗口里 `<video>` 失去 alpha

**现象**：透明 WebM 放进去，背景变成白块。

**根因**：Chromium 的透明窗口对 video 图层不做 alpha 合成。

**解法**：把视频逐帧画到 `<canvas>`（canvas 保留 alpha）：

```js
ctx.clearRect(0, 0, w, h);
ctx.drawImage(video, 0, 0, w, h);
```

## 4. Win+D 把她一起最小化

**现象**：按 Win+D 后她消失，回不来。

**解法**：监听 `minimize` 立刻恢复：

```js
win.on("minimize", () => setTimeout(() => win.restore(), 80));
```

配合 `watcher.exe` 每 30ms 判断"前台是不是桌面"，是就把她提到最上层。

## 5. Electron 启动即退出，没有报错

**现象**：`electron.exe` 一闪而过，无日志。

**根因**：环境里有 `ELECTRON_RUN_AS_NODE=1`（SnowLuma 会设置），Electron 被当成 Node 跑。

**验证**：`electron.exe --version` 输出的是 Node 版本（v20.x）而不是 Electron 版本。

**解法**：启动前清掉这个环境变量。

## 6. 计划任务每 5 分钟弹黑窗

**现象**：每隔几分钟屏幕上闪一下 PowerShell 窗口。

**根因**：`schtasks` 里写的 `powershell.exe -WindowStyle Hidden` 仍会先创建控制台。

**解法**：用 VBS 静默启动：

```vbs
Set sh = CreateObject("WScript.Shell")
sh.Run "powershell.exe -NoProfile -ExecutionPolicy Bypass -File ""E:\QQ-Bot\watchdog.ps1""", 0, False
```

计划任务改成 `wscript.exe "watch-hidden.vbs"`，并勾选"隐藏"。

## 7. 字幕和声音不同步

**现象**：她说完一半，字幕才出几个字。

**根因**：字幕用固定打字速度（每秒 9 字），跟音频时长无关。

**解法**：字幕按 `audio.currentTime / duration` 比例出字；口型按 `AnalyserNode` 音量。
实测：0.15s→"爸"，0.55s→"爸爸"，1.77s→"爸爸爸爸！"。

---

## 8. 合成的声音"没有起伏"

**现象**：复刻出来的声音平，像念稿。

**根因**：参考音频是平缓的讲故事，模型只学到那个语气。

**解法**（按性价比）：
1. `pitch_rate` +10~15（F0 标准差 43.6 → 48.5）
2. 情绪参数 + 感叹号（可达 60.2）
3. 换更有起伏的参考音频重新训练（根治）

---

## 9. 火山接口一直 `resource not granted`

**根因**：服务开通后需要几分钟生效；或资源包没开通。

**解法**：控制台确认「语音合成 2.0」「声音复刻 2.0」都已开通，等 5 分钟再试。
`X-Api-Resource-Id` 用 `seed-icl-2.0`（复刻音色）。

---

## 10. 声音复刻 API 报 `add unmapped key audios`

**根因**：`audios` 字段要传 **base64 字符串**，不是对象/数组。

**解法**：`{"speaker_id": "S_xxx", "audios": "<base64>", "language": 0, "model_types": [4]}`。
但**新建 speaker 仍要求在控制台下单**，API 不能凭空建音色。

---

## 11. QQ 消息中文变问号

**根因**：PowerShell 发送时用了默认编码。

**解法**：请求体用 UTF-8 字节数组 + `Content-Type: application/json; charset=utf-8`。

---

## 12. 桥接连不上 DSH

**根因**：DSH 每次启动端口会变。

**解法**：`watchdog.ps1` 每 5 分钟扫描监听端口，写回 `config.json` 并重启桥接。

---

## 13. 用 PowerShell 截图/点击时坐标全错

**根因**：进程是 DPI-unaware，系统给它的是缩放后的坐标（150% 时差 1.5 倍）。

**解法**：先 `SetProcessDpiAwarenessContext(-4)`（PerMonitorV2），再截图/移动鼠标。

---

## 14. yuyaya 的 `/api/chat` 返回空

**根因**：字段名是 `reply` 不是 `text`；中文在 PowerShell 里显示为乱码是终端编码问题，不是数据问题。

**解法**：`$r.reply` 并注意 UTF-8 输出。
