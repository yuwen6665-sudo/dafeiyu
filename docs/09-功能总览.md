## 五、建议的下一步顺序

```
第 1 步  ¥50 熔断 + API key 改环境变量      （用之前先把钱看住）
第 2 步  壁纸 = 她的房间                    （桌面感最后一块）
第 3 步  按住说话（ASR）                    （从"她说话"到"跟她说话"）
第 4 步  作息 + 情绪联动                    （她不再永远同一个状态）
第 5 步  房间走动 + 家具交互                （从"站着"到"生活"）
第 6 步  记忆可查看/编辑 + 冲突和好         （关系深度）
第 7 步  手机端（买手机 → dsh-go → 同一间房）
第 8 步  自主生活（日程 → 刷抖音/查资料 → 日记）
```

理由：先守住钱和安全 → 补上"桌面即房间"的观感 → 打通语音最影响体验 → 再谈生活与关系。
