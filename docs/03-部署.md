# 部署（Windows）

从零到"她住在你电脑里"，按顺序做即可。全程大约 1–2 小时，主要时间花在装 QQ 通道和训练音色上。

---

## 0. 目录规划

建议所有东西放同一个根目录，下面假设 `E:\QQ-Bot\`：

```
E:\QQ-Bot\
├── yuyaya\            # 房间服务
├── yy-bridge\         # 其实是 qq-bridge
├── SnowLuma\
├── yusheng-desktop\   # 桌面挂件（本仓库 desktop/）
├── tts\               # 本仓库 tts/
├── persona\           # 本仓库 persona/
└── tts-out\           # 合成出来的语音
```

## 1. 装大脑（DSH）

1. 安装 DeepSeek Harness 桌面端，登录
2. 确认它能正常对话
3. 记住它监听的端口（`Get-NetTCPConnection -State Listen` 里 50k–65k 那个）

> DSH 每次重启端口会变，所以 `scripts/watchdog.ps1` 会自动发现并写回 qq-bridge 配置。

## 2. 训练她的声音（火山）

1. 注册火山引擎 → 豆包语音 → **声音复刻 2.0**（需要开通，有免费额度）
2. 录一段 30–60 秒**干净**的说话（不要背景音乐、不要多人）
3. 上传 → 训练 → 得到 **音色 ID**（`S_xxxxxxxx`）
4. 在「API Key」页拿 **AppID** 和 **Access Token**
5. 设置环境变量：

```powershell
[Environment]::SetEnvironmentVariable('VOLC_TTS_APPID','你的AppID','User')
[Environment]::SetEnvironmentVariable('VOLC_TTS_TOKEN','你的Token','User')
[Environment]::SetEnvironmentVariable('VOLC_TTS_SPEAKER','S_xxxxxxxx','User')
```

6. 测试：

```powershell
powershell -File tts\tts.ps1 -Text "爸爸 你回来啦" -Out "$env:TEMP\a.mp3"
start "$env:TEMP\a.mp3"
```

**听不到？** 按顺序查：AppID 对不对 → Token 是否过期 → 音色 ID 是否属于这个 AppID →
资源包是否开通（错误码 `45000030` 就是没开通）。

## 3. 起房间

```powershell
git clone https://github.com/Lin-A1/yuyaya.git E:\QQ-Bot\yuyaya
cd E:\QQ-Bot\yuyaya
pip install -r requirements.txt
```

按 `room/patches/README.md` 打 5 处改动（新增 tts.py、挂 /api/tts、system_file、CloudVoice、复制页面）。

配置大脑（`config.json`）：

```json
{
  "default": "yusheng",
  "brains": {
    "yusheng": {
      "type": "openai",
      "label": "于笙",
      "base_url": "https://api.deepseek.com",
      "model": "deepseek-chat",
      "api_key_env": "DEEPSEEK_API_KEY",
      "system_file": "E:/QQ-Bot/persona/于笙.md",
      "extra": { "temperature": 1.15, "max_tokens": 260 }
    }
  }
}
```

启动：

```powershell
python -m server
# http://127.0.0.1:8848/room.html
```

## 4. 接 QQ

### 4.1 SnowLuma

1. 下载 SnowLuma，解压到 `E:\QQ-Bot\SnowLuma`
2. 启动，扫码登录你的**小号**
3. 记下 OneBot 的 `access_token`（WebUI → 配置）

### 4.2 qq-bridge

```powershell
cd E:\QQ-Bot
# 装（按上游 README）
copy yusheng-github\qq\config.example.json qq-bridge\config.json
```

填 `config.json`：

| 字段 | 填什么 |
|---|---|
| `snowluma.accessToken` | SnowLuma 的 token |
| `dsh.baseUrl` | `http://127.0.0.1:<DSH端口>` |
| `allow.private` | 你的 QQ |
| `allow.groups` | 群号 |
| `consoleToken` | 随便一串随机字符 |

然后按 `qq/PATCHES.md` 打两个补丁（夜间静音、私聊不主动）。

### 4.3 人格卡

把 `persona/于笙.md` 放进 `qq-bridge/roles/于笙.md`，配置里 `role.name = "于笙"`。

### 4.4 语音侧车

```powershell
powershell -File yusheng-github\qq\voice-sidecar.ps1
```

它会轮询 OneBot 历史消息，命中场景就发语音条。**首次启动会预热历史，不会给你补发旧语音。**

## 5. 桌面挂件

```powershell
cd yusheng-github\desktop
# 下载 Electron 33.x 解压到 electron/
powershell -ExecutionPolicy Bypass -File build.ps1
$env:ELECTRON_RUN_AS_NODE=$null
.\electron\electron.exe
```

## 6. 开机自启 + 看门狗

```powershell
# 自启
schtasks /Create /TN "YuSheng-Autostart" /SC ONLOGON /DELAY 0000:30 ^
  /TR "wscript.exe \"E:\QQ-Bot\start-hidden.vbs\"" /F

# 看门狗
schtasks /Create /TN "YuSheng-Watchdog" /SC MINUTE /MO 5 ^
  /TR "wscript.exe \"E:\QQ-Bot\watch-hidden.vbs\"" /F
```

两个 `.vbs` 的作用是**静默启动 PowerShell**（否则每 5 分钟弹一次黑窗）：

```vbs
Set sh = CreateObject("WScript.Shell")
sh.Run "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File ""E:\QQ-Bot\watchdog.ps1""", 0, False
```

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `45000030 resource not granted` | 火山服务没开通 | 控制台开通「语音合成 2.0」「声音复刻 2.0」，等 5 分钟 |
| QQ 中文变问号 | 请求体编码 | PowerShell 里用 UTF-8 byte[] + `charset=utf-8` |
| 桥接连不上 DSH | 端口变了 | 跑 `watchdog.ps1` |
| 桌面挂件整屏白 | Electron 透明窗口配置 | 见 `desktop/README.md` 的坑 2 |
| 桌面挂件启动就退出 | `ELECTRON_RUN_AS_NODE=1` | 启动前清掉这个变量 |
| 语音侧车晚上发语音 | 没配静音 | 侧车本身不限时，可在脚本里加时间判断 |
