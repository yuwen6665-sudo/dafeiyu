# 需求翻译对照表

> 用途：把"感觉/想法"翻译成可讨论的术语，并划清边界。
> 每次你说一个想法，我按下面的格式回一张卡：**原话 → 术语 → 边界 → 验收 → 待确认**。

## 翻译卡的格式

```
【原话】你当时怎么说的
【术语】这个功能在技术/产品上叫什么
【我理解】一句话说清它是什么
【边界·做】明确在范围内的事
【边界·不做】明确排除的事（防止期望膨胀）
【验收】怎么算做完
【待确认】我需要你拍板的点
```

## 已经翻译过的（本项目）

| 你的原话 | 专业术语 | 边界 | 现状 |
|---|---|---|---|

| "不要真开播，但是有虚拟形象有声音" | **非直播型虚拟形象**（Non-broadcast Avatar） | 做：本地形象 + 语音<br>不做：OBS 推流、平台开播 | ✅ |
| "她可以自己刷抖音玩、自己查资料" | **自主行动**（Autonomous Agency） | 做：滑/看/点赞、搜索后转述<br>不做：评论、私信、下单、改资料 | ⬜ |
| "手机打开就是她所在的空间" | **跨端同一场景**（Cross-device Scene Sync） | 做：同一房间、同一状态、同一记忆<br>不做：两份独立的她 | ⬜ |
| "一个开关开了就一直听着，随时能插话" | **常听 + 可打断**（Always-listening with Barge-in） | 做：本地唤醒 → 云端会话 → 打断<br>不做：24 小时云端长连（烧钱） | ⬜ |
| "她可以抖音或 QQ 微信给我发信息" | **主动触达**（Proactive Outreach） | 做：QQ 私聊主动<br>不做：微信（封号风险） | QQ ✅<br>桌面气泡 ✅ |
| "给她手机所有权限，手机上所有内容都能看" | **全设备授权**（Full Device Grant） | 做：屏幕/通知/无障碍/文件/定位<br>不做：不绑卡、不存证件（靠账号隔离） | 方案已定 ⬜ |
| "把她放进手机，单独一台手机" | **端侧自持**（On-device Autonomy） | 做：手机本机跑大脑 + 手机操控<br>不做：云手机（成本/风控） | ⬜ |
| "小 Q 版小肥娘，到处乱跑" | **精灵式桌面宠物**（Sprite Desktop Pet）+ **全屏自由移动**（Free Roaming） | 做：透明窗口、全屏移动、拖拽<br>不做：3D 模型（VRM/MMD） | ✅ 全屏漫游 |
| "不挡窗口" | **非侵入式层级**（Non-intrusive Z-order） | 做：点击穿透、桌面时浮出、其他窗口时下沉<br>不做：永远置顶（可选） | ✅ |
| "情感强度太低 / 起伏不够" | **韵律不足**（Prosody Deficiency） | 做：调 pitch_rate / emotion_scale / 标点<br>根治：换更有起伏的参考音频重训 | 🟡 部分改善 |
| "音画不同步，字幕也没跟上" | **音画同步**（Audio-Visual Sync） | 做：字幕按 `currentTime/duration` 推进；口型按音量<br>不做：逐字时间戳强制对齐 | ✅ |
| "没事和我发信息" | **主动发起对话**（Proactive Initiation） | 做：桌面气泡 8–15 分钟一次，概率 60%<br>不做：深夜（静默窗口） | ✅ 桌面 |
| "她要有自己的作息" | **时间驱动状态机**（Time-driven State Machine） | 做：犯困→睡→醒，影响动作与话量<br>不做：真实睡眠周期模拟 | ⬜ |
| "她要有记忆" | **长期记忆**（Long-term Memory） | 做：事实/偏好/事件，可查可改<br>不做：无损全量对话存储 | ✅ 插件 |
| "群聊里话痨、私聊不主动" | **分场景行为策略**（Channel-specific Policy） | 做：群聊主动问喜好；私聊等召唤<br>不做：群里刷屏 | ✅ |
| "她会生气、会冷战，但要给台阶" | **关系状态机**（Relationship State Machine） | 做：情绪状态 + 冷却时间 + 主动递台阶<br>不做：惩罚式冷暴力 | ⬜ |
| "只想要 50 块的预算" | **成本上限 + 降级策略**（Budget Cap & Degradation） | 做：到顶熔断、降级文字<br>不做：超额静默继续烧 | 文档 ✅<br>实现 ⬜ |

## 术语表（之后我会一直用这些词）

| 术语 | 一句话解释 |
|---|---|
| 场景（Scene） | 她所在的空间，含背景、家具、光照 |
| 精灵（Sprite） | 用序列帧/透明视频表示的角色 |
| 数字人（Digital Human） | 带表情、口型、动作的角色渲染层 |
| 大脑（Brain） | 决定说什么的模型/策略 |
| 通道（Channel） | 消息进出方式（QQ / 桌面 / 手机） |
| 层级（Z-order） | 窗口在前后关系中的位置 |
| 点击穿透（Click-through） | 鼠标点透明区域时穿透到下层 |
| 常听（Always-listening） | 麦克风常开、随时可对话 |
| 打断（Barge-in） | 她说话时你能插话，她立刻停 |
| 韵律（Prosody） | 语速、音高、停顿、情绪强度 |
| 音画同步（AV Sync） | 字幕/口型与音频时间轴一致 |
| 主动触达（Proactive） | 她主动发起消息/说话 |
| 自主行动（Agency） | 她自己在设备上操作软件 |
| 跨端一致（Cross-device） | 多设备看到同一个她 |
| 熔断（Circuit Breaker） | 超出预算自动降级/停止 |
